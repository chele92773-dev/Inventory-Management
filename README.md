# Inventory Management

## About the Project

I built this Inventory Management application using C# and ASP.NET Core MVC. The goal was to create a simple, practical way to keep track of products and inventory.

Users can add products, update information, search and filter the inventory, and keep an eye on stock levels.

## What It Can Do

- Add new products to the inventory
- Edit product information
- Delete products
- Search for products by name
- Filter products by category
- View product quantities and inventory totals
- Identify products that are running low on stock
- See inventory status at a glance

## Built With

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server LocalDB
- HTML and CSS
- Bootstrap
- Visual Studio

## Running the Project

1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Restore the NuGet packages.
4. Make sure SQL Server LocalDB is installed.
5. Build and run the application.

## A Little About the Project

This was a hands-on project where I put my C# and ASP.NET Core skills into practice. I enjoyed building the different features and seeing the application come together into something that could actually be used to manage inventory.
